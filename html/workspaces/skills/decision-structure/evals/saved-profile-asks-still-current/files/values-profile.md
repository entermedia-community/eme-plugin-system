# My values
1. **Family first**: Decisions that cost family time need a very good reason.
2. **Finish what you start**: Complete the current job before taking on a new one.
3. **Do it in person**: In person beats remote.
4. **Draw the plan**: A sketch before the build.
5. **Write it down**: Decisions not written down get relitigated.
6. **Buy once, buy well**: Pay more for gear that lasts.
7. **Rest matters**: No weekends except emergencies.
8. **Pay on time**: Staff and vendors get paid promptly.
9. **Test small before committing**: Cheap mistakes early.
10. **Teach by doing**: Shadowing beats manuals.
